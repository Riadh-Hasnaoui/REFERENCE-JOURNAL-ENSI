\begin{abstract}
Large Language Model (LLM)-based agents are rapidly transforming software engineering practice,
yet the fundamental question of how these systems represent entire code repositories remains
poorly understood. A repository is not merely a collection of files; it is a rich, interconnected
artifact encompassing call graphs, dependency networks, semantic relationships, historical
evolution, and domain-specific conventions. Without effective repository representation,
LLM-based agents cannot reliably perform complex tasks such as cross-file code completion,
project-level bug localization, feature implementation, code translation, or automated issue
resolution.

This paper presents the first systematic literature review (SLR) focused specifically on
\emph{repository representation paradigms} (PARs) in LLM-based software engineering.
Following the Kitchenham and Charters guidelines for SLR in software engineering and the
PRISMA 2020 reporting standard, we analyzed 160 primary studies published between 2020 and
2026. From this corpus, we derive a seven-pillar taxonomy of repository representation
paradigms: (\parcmd{1}) dense token embeddings, (\parcmd{2}) retrieval-augmented generation,
(\parcmd{3}) graph-based structural representations, (\parcmd{4}) dynamic and execution-based
context, (\parcmd{5}) summarization and compression, (\parcmd{6}) memory-augmented agent
architectures, and (\parcmd{7}) multi-step agentic frameworks.

We map each paradigm bidirectionally against seven software engineering tasks and evaluate
their trade-offs across five dimensions: context coverage, retrieval latency, training cost,
scalability, and benchmark availability. Our findings reveal that while \parcmd{2} (RAG)
dominates current practice, \parcmd{3} (graphs) and \parcmd{7} (agentic) are rapidly gaining
adoption for complex tasks. We identify critical gaps including the absence of longitudinal
benchmarks, under-explored multi-paradigm hybrids, and the need for energy-aware evaluation
metrics. This survey provides researchers and practitioners with a comprehensive reference for
selecting and designing repository representation strategies for LLM-based software engineering
agents.
\end{abstract}
