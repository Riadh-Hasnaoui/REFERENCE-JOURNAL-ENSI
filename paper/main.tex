\begin{abstract}
Large Language Model (LLM)-based tools for repository-level software engineering
tasks have proliferated rapidly, yet no systematic study has characterised the
\emph{representation paradigms} through which these systems encode an entire
code repository into model context.  This Systematic Literature Review (SLR),
conducted following Kitchenham~\cite{kitchenham2007guidelines} and augmented
with Wohlin snowballing~\cite{wohlin2014snowballing}, synthesises $N=163$
primary studies through a novel seven-dimension taxonomy spanning seven
Paradigm~classes~(PAR-1--PAR-7), six Task~Objectives~(O1--O6), and a
Technology~Readiness~Level~(TRL) scale.  We identify five critical research
gaps and derive a concrete Research Agenda for the global SE community.
\end{abstract}
