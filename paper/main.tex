%%% Abstract ──────────────────────────────────────────────────────────────────
\begin{abstract}
Large Language Models (LLMs) have demonstrated remarkable capabilities across
software engineering (SE) tasks, yet a fundamental question remains
systematically underexplored: \emph{how} do LLM-based systems represent an
entire code repository as context?
We call this the \emph{Repository Representation Problem} (RRP) and conduct
the first Systematic Literature Review (SLR) dedicated to it.
Following a rigorous five-pillar methodology integrating Kitchenham's SLR
guidelines, Wohlin's snowballing procedure, PRISMA~2020 reporting standards,
Cruzes and Dyb{\aa}'s thematic synthesis, and the ACM SIGSOFT Empirical
Standards, we analyse 159 primary studies published between 2020 and early 2026.
Our main contribution is a \textbf{seven-paradigm taxonomy}: (1)~dense code
embeddings, (2)~retrieval-augmented context, (3)~graph-based structural
representations, (4)~execution and dynamic representations,
(5)~memory-augmented context, (6)~compression and summarization, and
(7)~agentic iterative exploration.
Each paradigm is characterised along ten analytical dimensions (context
representation type, granularity, construction pipeline, computational
complexity, token budget, context freshness, semantic precision, scalability,
cross-file dependency support, and training dependency) and mapped against
seven SE objectives (code completion, code generation, program repair, fault
localization, code search, code translation, test generation).
We further provide empirical evidence that the static-repository assumption
embedded in three paradigms introduces a 10--61\% evaluation bias, identify
11 open research challenges, and derive a structured research agenda.
A complete PRISMA~2020 flow diagram and checklist accompany the paper.
\end{abstract}
