\begin{abstract}
Large Language Models (LLMs) have become central to a new generation
of automated software engineering (SE) tools, yet a persistent
structural challenge hampers their adoption in real-world settings:
\emph{the repository gap}.
Industrial software systems are vast, multi-file, interdependent
codebases, while LLMs operate natively on short, isolated code
snippets.
Bridging this gap requires purpose-built mechanisms to extract,
structure, and inject repository-level context into LLM
processing pipelines---a problem for which the research community
has proposed a remarkable diversity of approaches over the past
three years.

This paper presents the first Systematic Literature Review (SLR)
dedicated to \emph{classifying and comparing the full spectrum
of code repository representation strategies for LLM-based SE}.
Following the Kitchenham \& Charters methodology and PRISMA 2020
reporting guidelines, we systematically searched seven major
digital libraries and retained \textbf{N} primary studies published
between 2020 and early 2026 after applying seven inclusion and
six exclusion criteria.
From this corpus, we induce a \textbf{seven-paradigm taxonomy}:
(PAR-1) Repository-Level Code Embedding \& Dense Representation;
(PAR-2) Retrieval-Augmented Cross-File Context Construction;
(PAR-3) Graph-Based \& Structural Representation;
(PAR-4) Execution \& Dynamic Representation;
(PAR-5) Memory-Augmented Context;
(PAR-6) Compression \& Summarization; and
(PAR-7) Agentic \& Iterative Context Exploration.

We systematically map each paradigm to seven SE downstream
objectives---code completion, code generation, code search,
bug fixing, refactoring/translation, test generation, and code
review---and evaluate their comparative performance across
standardized benchmarks including SWE-bench, CrossCodeEval,
RepoBench, and DevEval.
Our analysis reveals critical design trade-offs, identifies
paradigm combinations that consistently outperform single-paradigm
approaches, and exposes important open challenges in scalability,
reproducibility, and multilingual support.
This work provides both a rigorous reference map for researchers
entering the field and actionable design guidelines for
practitioners building repository-aware LLM-based SE systems.
\end{abstract}
