\title{How Do LLM-Based Agents Represent Code Repositories?\\
       A Systematic Literature Review}

\author{Anonymous}
\affiliation{\institution{Anonymous Institution}}
\email{anonymous@example.com}

\begin{abstract}
Large Language Models (LLMs) have demonstrated strong capabilities on isolated
coding tasks, yet their effective deployment for \emph{repository-level}
software engineering (SE) tasks---spanning cross-file code completion,
automated bug fixing, test generation, and refactoring---fundamentally depends
on how an entire code repository is represented and fed into the model context.
This systematic literature review (SLR) synthesises 163~primary studies
published between 2020 and 2025 to answer three research questions: (RQ1)~what
paradigms of repository representation exist; (RQ2)~how they map to principal
SE objectives; and (RQ3)~what operational trade-offs govern paradigm selection.
We introduce a seven-class taxonomy (\textbf{PAR-1: Dense Embeddings} through
\textbf{PAR-7: Agentic Exploration}), a $7\times5$ bidirectional mapping
matrix, and a multi-dimensional trade-off framework covering semantic
precision, token budget, construction latency, context freshness, and
scalability.  We identify five open research gaps and provide a forward-looking
research agenda.  All supporting artefacts are archived in an online
replication package (Zenodo).
\end{abstract}

\keywords{systematic literature review, repository representation,
