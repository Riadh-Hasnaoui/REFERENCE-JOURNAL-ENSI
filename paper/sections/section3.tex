\section{Taxonomy of Repository Representation Paradigms}
\label{sec:taxonomy}

We identified seven distinct paradigms (\textbf{PAR-1} to \textbf{PAR-7})
from the corpus of 163~primary studies through thematic synthesis
(Section~\ref{subsec:synthesis}).

\subsection{PAR-1: Dense Embedding Retrieval}
Dense vector representations of code units (functions, files, or hunks) are
stored in an embedding index.  At query time, the $k$ most similar units are
retrieved by cosine similarity.  Representative work:
CodeBERT~\cite{feng2020codebert}, GraphCodeBERT~\cite{guo2021graphcodebert},
UniXcoder~\cite{guo2022unixcoder}.

\subsection{PAR-2: RAG-Based Cross-File Retrieval}
Retrieval-Augmented Generation (RAG) pipelines retrieve cross-file context
on demand.  Representative work: RepoCoder~\cite{zhang2023repocoder},
Repoformer~\cite{wu2024repoformer}.

\subsection{PAR-3: Graph-Based Structural Representation}
Abstract Syntax Trees (AST), Control-Flow Graphs (CFG), Call Graphs, Data-Flow
Graphs (DFG), or Knowledge Graphs encode structural relationships.
Representative work: GraphCoder~\cite{liu2024graphcoder},
CodexGraph~\cite{liu2025codexgraph}.

\subsection{PAR-4: Execution-Trace / Dynamic Representation}
Runtime signals (test results, stack traces, coverage data) augment static
context.  Representative work: SWE-bench~\cite{jimenez2024swebench}.

\subsection{PAR-5: Adaptive Memory Mechanisms}
Persistent, session-aware memory that is updated iteratively as the agent
edits code.  Representative work: CodeMEM~\cite{wang2026codemem}.

\subsection{PAR-6: Compression / Summarisation}
Token-budget-aware compression or hierarchical summarisation reduces long
contexts.  Representative work: LongCodeZip~\cite{shi2025longcodezip}.

\subsection{PAR-7: Agentic Repository Exploration}
Autonomous agents issue tool calls (file read, search, shell commands) to
build a context on-the-fly.  Representative work:
SWE-agent~\cite{yang2024sweagent}.
