\section{Introduction}\label{sec:introduction}

The industrialisation of LLM-based coding assistants—from IDE auto-completions
to autonomous software agents capable of resolving GitHub issues end-to-end—has
created an urgent need to understand \emph{how} these systems represent an
entire code repository as model context.  A repository is not a single file; it
is a multi-artefact, multi-language, temporally evolving socio-technical
system.  The strategies used to encode this complexity directly determine what
tasks are feasible, at what quality, and at what computational cost.

This Systematic Literature Review addresses four Research Questions:
\begin{description}[leftmargin=1.8cm,labelwidth=1.6cm,labelsep=0.2cm]
  \item[\textbf{RQ1}] What paradigms do LLM-based systems use to represent code
    repositories, and how prevalent is each paradigm?
  \item[\textbf{RQ2}] What task objectives do these systems target, and what
    evaluation benchmarks are employed?
  \item[\textbf{RQ3}] What is the technology readiness level (TRL) of each
    paradigm across task objectives?
  \item[\textbf{RQ4}] What critical research gaps exist, and what research
    directions would most effectively advance the field?
\end{description}
