Code search, which retrieves relevant code snippets from a large codebase based on natural language queries, significantly
enhances software development efficiency and quality, with effective code representation being crucial for its success. While
recent studies leverage both syntactic and semantic structures of code snippets to improve representation, they inadequately
address two key challenges: (1) inadequate capture of long-range dependencies in these structures, and (2) ineffective fusion
of syntactic and semantic information. To overcome these limitations, we propose CoSrch, a deep model for syntactic and
semantic-aware code representation. CoSrch first encodes code snippets as graphs to enable structured alignment and fusion,
then employs a GNN-based graph encoder to capture long-range dependencies (addressing Challenge 1), along with an
overlap-aware modality decomposition and fusion framework that eliminates redundancy when fusing the syntactic and
semantic information (resolving Challenge 2). Extensive experiments on prominent benchmarks demonstrate CoSrch’s
superiority, achieving at least a 7.60% improvement in SuccessRate@1 and a 5.41% gain in MRR on the CSN-Java dataset
compared to the best baseline, validating its effectiveness in advancing code search performance.

1       Introduction
The rapid growth of open-source software communities, especially through platforms such as GitHub1 and Stack
Overflow2 , has significantly enhanced the accessibility and availability of large-scale shared code repositories.
Empirical studies [46, 57] demonstrate that more than 90% of software development efforts focus on reusing
existing code. Given this overwhelming reliance on code reuse, effective code search mechanisms which enable
developers to efficiently locate relevant code snippets within those extensive code repositories are crucial for
improving software productivity and quality while simultaneously reducing development costs [27, 50].
   Early code search methods [9, 33, 41, 47, 50, 51] primarily rely on traditional information retrieval (IR)
techniques, such as sparse vector retrievers (e.g., TF-IDF and BM25 [54]). However, these approaches treat
both queries and codes as plain texts and simply match source code snippets based on the presence of query
keywords, thereby neglecting the crucial semantics embedded within both queries and codes (e.g., function
names and variable roles in a code snippet). The advent of deep learning (DL) has played a pivotal role in
capturing the semantic information of both code and natural language queries through advanced neural network
architectures [8, 21, 66]. Specifically, most modern deep code search methods employ sequential models, such
as convolutional neural networks (CNNs) [38], long-short-term memory networks (LSTMs) [59], self-attention
mechanisms [61], and co-attention mechanisms [6], to learn semantic representations of queries and codes
separately and then measure their semantic relevance using cosine similarity. While the semantic features of
queries and code snippets have been successfully extracted, sequential models often neglect the syntactic structure
of code snippets, which is crucial for reflecting their functional characteristics [7]. To address this issue, recent
studies [15, 19, 24] have proposed representing the syntactic structure of code snippets as Abstract Syntax Trees
(ASTs) [52]. Then, for each code snippet, its AST-based syntactic structure is encoded using graph neural networks
(GNNs) [55], while its semantic features are encoded using a sequence encoder, after which the two aspects of
encoding results are merged to derive a unified representation of the code snippet.
   However, existing deep code search models are still limited in two major aspects, reducing their search
performance.
      • Challenge 1: Inadequate capture of long-range dependencies in code structure. Long-range
        dependencies in code syntactic (or semantic) structure are essential for capturing data and control flow
        across the code, thereby enhancing models’ ability to identify patterns and context, and improving code
        understanding [44, 71]. However, recent attempts to address this challenge by increasing the depth of
        GNNs that model graph-based code structures [49, 63] have inadvertently led to two critical issues: over-
        squashing [3] and over-smoothing [40]. These two issues degrade the models’ ability to learn differentiated
        node representations, ultimately affecting the quality of the generated code representations.
      • Ineffective fusion of code syntactic and semantic information. For a given code snippet, the syntactic
        structure is typically represented as an AST graph, while semantic features are organized as a sequence. The
        inherent heterogeneity between these two representation modalities [21] poses significant challenges for
        effective integration, requiring sophisticated alignment mechanisms. Despite recent advances [13, 22, 65],
        existing fusion strategies fail to adequately address semantic redundancy between the graphical features
        and sequential features, leading to overlapping information [48] and reduced discriminative power in the
        final code representations.
   To address the aforementioned challenges, this paper presents a novel syntactic and semantic-aware deep
network named CoSrch, which effectively captures and fuses the syntactic and semantic structures of every
code snippet so as to provide a more accurate representation of it. In specific, given a query in natural language
towards a code base, CoSrch first constructs the semantic graphs for both the query and each code snippet in the

base using dependency parsing methods [32]. Concurrently, the syntactic graph of each code snippet is extracted
in the form of a abstract syntax tree (AST). Note that, in CoSrch, the syntactic and semantic structures of a
code snippet are both modeled as graphs. This unified representation facilitates the alignment and fusion of the
two structures in subsequent steps. Then, to address the two challenges facing by recent works, CoSrch designs
the overlap-aware modality decomposition and fusion framework (OA-MDFF) which contains two phases, i.e.,
overlap-aware modal decomposition (OA-MD) and multimodal fusion (MF). In specific, to address Challenge 1,
two GNN-based graph encoders are designed and deployed in the OA-MD phase, each of which is responsible
to encode the syntactic (or semantic) graph of a code snippet. Note that a encoder can capture both short- and
long-range dependencies in the syntactic (or semantic) structure of the code snippet by considering interactions
among different 𝑘-hop neighbor graphs of the code syntactic (or semantic) graph. This approach avoids learning
the long-range dependencies via the local aggregation paradigm of GNNs, which can produce less discriminative
node representations. To address Challenge 2, three loss functions are firstly proposed in the OA-MD phase which
target at extracting the overlapping and non-overlapping information from the two modalities (i.e., syntactic and
semantic graphs), separately. Subsequently, in the MF phase, two decoders are designed: one decoder focuses
on deriving the overlapping information (𝔽∩ ), while the other computes the non-overlapping information (𝔽− )
from the decomposed outputs of the OA-MD phase, thereby reducing redundancy between modalities. Finally,
the final representation for the code snippet are derived by combing 𝔽∩ and 𝔽− . To evaluate the effectiveness of
the proposed CoSrch model in code search tasks, we compare it with 11 state-of-the-art models using C, Java,
Python and JavaScript datasets. Three standard evaluation metrics are employed: SuccessRate@k, MRR, and
Precision@k. Experimental results demonstrate that CoSrch achieves significant performance improvements
compared to all baselines. Meanwhile, ablation studies verify the effectiveness of each individual module in
CoSrch. The source code of CoSrch is publicly available at: https://github.com/sincerity-being/CoSrch.
   The main contributions of this work are:


     • We propose CoSrch, a novel syntactic and semantic-aware deep network for effective code search. Different
       from previous works, both the syntactic and semantic structures of a code snippet are consistently modeled
       by graphs, which facilitates the follow-up alignment and fusion of these two modalities.
     • CoSrch introduces an overlap-aware modality decomposition and fusion framework (OA-MDFF) to
       enhance code representation learning. On one hand, OA-MDFF captures both short- and long-range
       dependencies in syntactic (or semantic) graphs by learning interactions across different 𝑘-hop neighbor
       graphs of the code syntactic (or semantic) graph, effectively addressing Challenge 1. On the other hand, it
       eliminates redundancy between syntactic and semantic graphs before fusing them, resolving Challenge 2.
       By tackling these key limitations of prior works, CoSrch improves the final representations of each code
       snippet, leading to higher-quality code search results.
     • Extensive experiments are carried out on multiple prominent code search datasets respectively corre-
       sponding to several widely-used programming languages, e.g., Java and Python. The experimental results
       deliver that the proposed CoSrch model surpasses all state-of-the-art methods in terms of handling code
       search task.


   The remainder of this paper is organized as follows: Section 2 presents motivating examples of the proposed
CoSrch model. Section 3 introduces preliminaries, including syntactic and semantic graph construction and
the formalized problem studied in this work. Section 4 elaborates the implementation of the CoSrch model.
Section 5 presents the experimental setup and reports the results. Section 6 reviews related works. Finally, Section
7 concludes the paper and points out future research directions.

2       Motivating Examples
This section presents running examples to demonstrate the effectiveness of our CoSrch model in addressing the
syntax- and semantics-aware code search challenges outlined in Section 1.
   Recent advances in GNNs [49, 67] have demonstrated their effectiveness in modeling short-range node
dependencies within code snippet graphs, yet propagating long-range dependencies remains a persistent challenge
for traditional GNN-based learning [58] which learns the node dependencies by the local aggregation paradigm,
i.e., iteratively aggregating information from immediate neighbors via message propagating mechanisms. In such
case, increasing GNN depth could theoretically capture long-range node dependencies. However, the deeper
architecture of GNNs suffers from two critical issues: over-squashing [3] and over-smoothing [40]. The over-
squashing issue refers to the distortion and compression of information from distant nodes during message
propagation, severely limiting the model’s ability to capture long-range dependencies. On the other hand, the
over-smoothing issue occurs when repeated message-propagating iterations cause node representations to
become indistinguishable, losing their discriminative power. Since long-range dependencies between nodes in
code semantic or syntactic graphs of a code snippet are crucial for accurately modeling program logic (e.g.,
nested block dependencies), these two issues fundamentally prevent GNNs from effectively learning long-range
dependencies in the code structure graphs. Consequently, this limitation degrades the quality of learned code
representations and ultimately compromises the performance of code search tasks.

dependencies of varying lengths, ultimately improving performance in subsequent code search tasks.

3       Preliminaries
Section 3.1 explains the generation of syntactic (or semantic) graph for a query (or code snippet). Subsequently,
the code search task is formally defined from a unified perspective of the graph in Section 3.2.

3.1      Syntactic and Semantic Graph Construction
Inspired by [44], the graph has a more powerful ability to model rich semantic structure information from a code
snippet than the sequential structure. Consequently, in the CoSrch model, the semantic structure of a query in
a natural language representation or a code snippet is also constructed as a graph (called the semantic graph),
while the syntactic structure of a code snippet has been generally modeled by the AST.
3.1.1 Syntactic Graph Construction. In our solution, the syntactic graph of a code snippet is represented by the
AST [53], which is built following the idea of [1]. The AST is a tree representation of the syntactic structure
of the code snippet. Specifically, the syntactic graph based on AST of a code snippet is formally denoted as
𝒢△𝑐 (𝒱△𝑐 , ℰ△𝑐 ), where 𝒱△𝑐 is a set of nodes in the AST, and ℰ△𝑐 symbolize the edges that delineate relationships
between nodes. As illustrated in Figure 2(e), every node in the constructed syntactic graph 𝒢△𝑐 for the code
snippet shown in Figure 2(c) signifies a distinct structure in the code. Note that a leaf node in 𝒢△𝑐 can represent a

variable (i.e., “x”), a function (i.e., “func”), an operator (i.e., “+”), or a literal (i.e., “1”), while an intermediate node
denotes various compilation units, such as “block”, “assignment”, and “binary_operator”.

3.1.2 Semantic Graph Construction. The constituency parse tree [32], which models composition and ordering
information of sentences, is commonly employed for extracting semantic structure from natural language
texts [49]. Considering the proposed queries of users over a code base are generally represented in the form of
natural languages, extracting the semantic structure from the queries using the idea of constituency parse tree is
very natural. With respect to the semantic structure of a code snippet, existing works propose to model such
information using a data flow graph (DFG) [23]. Figure 2(f) illustrates the constructed DFG of the code snippet
in Figure 2(c). However, we argue that a DFG-based solution has some limitations. On one hand, DFG-based
solution can only capture the variable value flow and fails to model the semantic control structure of a code
snippet which is vital information delivered by the code. On the other hand, when the semantic structure of a
user query is extracted by a constituency parse tree, representing the semantic structure of code snippet by a
DFG leads to the semantic understanding gap between these two structures. In view of two limitations, in this
paper, we propose to consistently adopt the constituency parse tree to build the semantic graph for each code
snippet, due to the resemblance between codes and natural languages [10, 26]. Specifically, the semantic graph
for a query 𝑞 (or a code snippet 𝑐) is denoted by 𝒢𝑞 = (𝒱𝑞 , ℰ𝑞 ) (or 𝒢𝑐 = (𝒱𝑐 , ℰ𝑐 )), where 𝒱 is a set of nodes with
each node representing a token in 𝑞 (or 𝑐) and ℰ is a set of edges with every edge denoting the relation between
two connected tokens in 𝑞 (or 𝑐). For example, considering the query 𝑞 =“Return the sum of two numbers”
displayed in Figure 2(a), the semantic graph for the query is shown in Figure 2(b). As indicated by the figure, S
serves as the designated root symbol, an intermediate node represents the grammatical properties of verbs (i.e.,
VP) or the composition of nouns (i.e., NP), and a leaf node corresponds to a token in the text sequence of the
query 𝑞. Meanwhile, the red edge in the graph represents the word ordering relation between two tokens in the
text sequence of the query, while the blue edge linking an intermediate node and a leaf node denotes the grammar
rule relation between them. The constructed semantic graph for the code snippet in Figure 2(c) is provided in
Figure 2(d). Figure 2(b) and Figure 2(d) illustrate that the semantic graph for a query or (a code snippet) built in
the proposed CoSrch model summarizes all implicit semantic relationships [69] (i.e., word ordering and grammar
rules) in it.

4       Our Approach
In this section, we outline the CoSrch workflow and provide a detailed description of each module’s structure. The
framework integrates query semantic graphs and code semantic (or syntactic) graphs, as illustrated in Figure 4.
It comprises four sequential modules: syntactic and semantic graph construction, overlap-aware modality
decomposition and fusion framework (OA-MDFF), query semantic encoder, and code search. As syntactic and
semantic graph construction is discussed in Section 3.1, we focus here on the remaining three modules. Given
that the graph encoder resolves Challenge 1 and involves technical complexity, we present its details at first in a
dedicated section.

4.1      Graph Encoder
Graph encoder is presented to efficiently capture short- and long-range node dependencies and facilitates the

4.2   Overlap-aware Modality Decomposition and Fusion Framework
To address Challenge 2 outlined in Section 1 regarding the ineffective fusion of syntactic and semantic information
in code snippets, the proposed CoSrch model introduces the an overlap-aware modality decomposition and fusion
framework (OA-MDFF). OA-MDFF systematically integrates the syntactic and semantic structure graphs of every
code snippet while preserving modality-specific characteristics and minimizing inter-modal redundancy [48].
The architecture of OA-MDFF mainly contains two phases, that is, overlap-aware modal decomposition (OA-MD)
which disentangles modality overlap and modality-specific representations, and multimodal fusion (MF) that
fuses the disentangled modality-specific and shared representations among modalities.
4.2.1 Overlap-aware Modal Decomposition. The two modalities, i.e., the semantic structure graph and the syntactic
structure graph of a code snippet, are encoded separately using the graph encoder introduced in Section 4.1 before
being fused. To capture both overlapping and distinct information between the two modalities (as illustrated in
Figure 4), two instances of the graph encoder are employed for each modality: the overlapping information encoder
(OI-encoder) and the non-overlapping information encoder (NOI-encoder). Given the semantic (or syntactic)
structure graph, the outputs of the OI-encoder are denoted as 𝜙 ∩ ∈ ℝ|𝒱|×𝑑 (or 𝜙△∩ ∈ ℝ|𝒱|×𝑑 ), while the outputs of
the NOI-encoder are represented as 𝜙 − ∈ ℝ|𝒱|×𝑑 (or 𝜙△− ∈ ℝ|𝒱|×𝑑 ).

gradually expanded [68]. This iterative process enables the graph encoder to progressively disentangle redundant
(overlapping) and non-redundant (non-overlapping) information across semantic and syntactic graphs.

both Java and Python datasets, while the final output vector dimension is set to 128. We employ Adam [35] for
optimization and apply LayerNorm [5] to each layer while tuning the other hyperparameters. We initialize the
learning rate to 0.001 and reduce it by a factor of 0.0005 when the improvement rate falls below 0.01, ultimately
determining the optimal learning rate to be 0.003. The gradient is clipped at a length of 10.0. We set the maximum
number of epochs at 6 and terminate the experiment if the MRR fails to improve for three consecutive epochs.
The size of the training batch is fixed at 1,000, consistent with previous research [29]. A batch containing 1,000
samples means that one correct code 𝑐𝑖 corresponds to the current query 𝑞𝑖 , while the remaining 999 code snippets
serve as distractors to differentiate from the current 𝑞𝑖 . We implement CoSrch using PyTorch 1.13.1 on a Linux
system with a GPU (A800-80G) and a CPU with 256GB of RAM.

           syntactic similarity of each code snippet from the training data and retrieving the most similar one for
           each. Additionally, it integrates a multi-perspective co-attention mechanism, utilizing CNNs to capture
           local correlations between code and query.
         • CAT [24] employs a sequence encoder to integrate two modalities, i.e., syntactic and semantic features,
           extracted from code tokens and their corresponding AST representations.
         • TabCS [66] fuses two modealities, i.e, code textual features, including method names, API sequences, and
           tokens, along with AST, and query features (tokens), using a two-stage attention network to improve
           representation for both code and query.
         • GraphSearchNet [49] suggests building graphs for both the source code and queries utilizing bidi-
           rectional Graph Gated Neural Networks (BiGGNN) [42] to capture the local structural information of
           both. Additionally, it enhances BiGGNN by integrating a multi-head attention module to capture global
           information within the code sequences, thereby enhancing the model’s learning capacity.
         • CodeBERT [17] is the first pre-trained model designed for natural language-programming language

         • GraphCodeBERT [23] builds upon CodeBERT by introducing a graph-guided masked attention mecha-

6 Related Works
6.1 Code Representation
Initially, research efforts on code representation primarily focused on token sequences [2, 21, 30]. The token-
based approach to code representation involves segmenting code snippets into sequences of tokens, with each
token being mapped to a real-valued vector. However, this approach tends to disregard the syntactic structure
information inherent in the code. Another technological route is to model the syntactic structure of codes using
the abstract syntax tree (AST) structure [53]. Notable works in this area include Tree-CNN [53], Tree-LSTM [60],
Code2vec [4], and DeepCom [28]. All these works propose to represent the AST structure by linearizing it into a
sequence of nodes using classical tree traversal strategies. Converting an AST structure to a node sequence will
compromise the 2D structural integrity of the AST structure. Thus, recent advancements in code representation
have seen the proliferation of graph-based approaches [1] for learning semantics of codes across various tasks,
including source code summarization [18, 52] and code search [44, 69]. As an example, MMF3 [52] integrates
the AST syntactic structure encoded by a GNN (named GCN [36]) with the semantic information extracted
from the code sequences via transformers, and as a result successfully enhance the performance of source code
summarization. Although GNN can extract the short-range dependencies among nodes in ASTs, it can rarely
capture the long-range dependencies among nodes in ASTs. Seeing this limitation, Gao and Lyu introduce a
multi-scale feature extraction method named M2TS [18]. M2TS can effectively capture diverse short&long-range
dependencies among nodes in the syntactic structure graph of a code snippet by considering multiple subgraphs

ACM Trans. Softw. Eng. Methodol.
                           CoSrch: Syntactic and Semantic Structure-Aware Code Representation for Effective Code Search •   29


with different scales. The computational burden of M2TS, however, raises very quickly with the increase of
the graph scale, due to the training of graph convolutional network for each subgraph. Moreover, there exists
constrained interaction among distinct subgraphs, hindering the comprehensive utilization of inter-subgraph
relationship information. Hence, it is imperative to investigate a more effective and efficient approach to extract
and then make use of the short&long-range dependencies among nodes in the syntactic structure graph of codes
for better code representation.

6.2   Code Search
Initially, code search approaches [33, 41, 51] primarily rely on technologies such as information retrieval (IR)
and natural language processing (NLP), which both consider the textual similarity between code snippets and
queries. Specifically, to improve the similarity comparison between codes and queries, Lu et al. [50] propose
to expand queries with their synonyms generated from WordNet and finally successfully enhance the hit ratio
of the code search task. CodeHow [51] provides another way of query expansion to improve the code search
performance. It first searches a code API repository based on each query, after which all retrieved APIs are
used as the supplementary information of the query. CodeMatcher [47], on the other hand, Optimizing the code
search procedure involves filtering out irrelevant or noisy keywords in a query or code snippet. However, all the
aforementioned approaches retrieve code snippets based solely on textual similarity between the query and code
snippet, thereby ignoring the more critical semantic-level similarity for effective query-code matching.
   With the advancement of NLP and deep learning, numerous works [8, 43, 56] have emerged which employ
deep neural networks to optimize the semantic representations of both queries and code snippets. DeepCS [21] is
the pioneering endeavor to use DNNs for code search tasks. Specifically, DeepCS employs multiple LSTMs to
encode code API sequences, code tokens, and function names, generating their vector representations. After that,
to alleviate the computational complexity of DeepCS, UNIF [8] introduces a straightforward bag-of-word model
with an attention mechanism, demonstrating enhanced performance of code search tasks. CARLCS-CNN [57] and
SAN-CS [16], on the other hand, leverage co-attention mechanisms [6] and self-attention networks respectively, to
achieve the semantic mapping from user queries to code snippets. While these models excel in capturing semantic
information between queries and code snippets, they neglect the semantic or syntactic structure information in
every code snippet, leading to less satisfactory searching results. Seeing this limitation, DGMS [44] proposes
to model the semantic or syntactic structure information in code snippets via the AST structure, which largely
preserves the structure information in them.
   In recent years, numerous studies have aimed to boost code search performance by fusing multi-modality
information within code snippets. For example, Haldar et al. [24] introduce CAT, which achieve effective code
search by enriching code representations via integrating the modal of code texts and the modal of AST syntactic
structures extracted from codes. Meanwhile, MMAN [63] presents a multi-modal attention fusion layer that assigns
weights to various segments within each modality of a code snippet, and those segments are then consolidated
into a unified hybrid representation of code snippet which captures the implicit semantic relations between
the code text and AST structure of the code snippet. MMAN [63], however, focuses solely on inter-modality
attention, overlooking the significance of intra-modality information [13]. TabCS [66] is another example. For a
certain code snippet, TabCS not only extracts its textual features (i.e., method name, API sequence, and tokens),
but also derives its syntactic structure features in the form of AST at first. After that, a two-stage attention
network structure employed in TabCS to learn interactions within a single feature modal or between two feature
modalities. Finally, Unixcoder [13] introduces a pre-trained multi-modal approach designed to comprehensively
explore the relationships between diverse modalities, such as code text and AST structure of code. However, these
methods primarily concentrate on maximizing the shared information across all modalities, while overlooking
the exploration of distinctive information unique to each modality. In code search, the syntactic and semantic

                                                                                            ACM Trans. Softw. Eng. Methodol.
30   •   Jia Xu et al.


structures of code snippets contain rich information that requires careful processing and effective fusion. However,
existing methods struggle to optimally fuse these modalities. To address this, we propose a novel decoupling
fusion method that reduces redundancy when integrating syntactic and semantic structures.

7    Conclusions and Future Works
Seeing the two challenges that are not well addressed in recent code search literature, this paper introduces
CoSrch, a novel syntactic and semantic structure-aware code representation deep model for effective code
search. Different from related works, CoSrch proposes to model both of the syntactic and semantic structure
information in a code snippet uniformly using graphs, to facilitate the alignment of the two types of structure
information when fusing them. Then, an effective encoding strategy is designed in CoSrch which can compute a
better representation for code (or query) based on adjacency matrices of a syntactic (or semantic) graph with
different orders, so as to ensure that long-range dependencies among nodes in the graph can be learned in
those representations (addressing Challenge 1). Moreover, we present a overlap-aware modality decomposition
and fusion framework in CoSrch, which eliminates the negative impact brought by the redundant information
between the two modalities of a code snippet, i.e., syntactic structure and semantic structure, on the quality
of the fused code representation based on the two modalities (addressing Challenge 2). Extensive experiments
conducted on Java and Python datasets demonstrate the superiority of our proposal over all baselines.
   Notice that the proposed CoSrch is a general deep network for representing codes written in different pro-
gramming languages. In the future, we plan to develop specific programming language-oriented optimization
strategies which consider characteristics of different programming languages.
